# Studio Diva's Hair — site

Static marketing site (Astro + Tailwind CSS v4 + TypeScript) for **Studio Diva's Hair – Salão de Beleza**, Indaiatuba/SP. Content is pt-BR; the main conversion is booking via WhatsApp. Hosted free on **GitHub Pages**: https://studiodivashair.github.io/

## Run locally

```bash
npm install
npm run dev        # http://localhost:4321
npm test           # unit tests for the opening-hours logic
npm run build      # static output in dist/
npm run preview    # serve dist/ locally
```

Node version: see `.nvmrc` (24).

## Edit content

Almost everything lives in **`src/data/site.ts`**: contact, hours, services (and optional prices), the "Sobre" text, reviews, the `features.showGallery` flag.

- **Public address:** one constant in `src/data/site-url.mjs`. Canonical URLs, Open Graph, JSON-LD, sitemap and `robots.txt` all follow it.
- **Photos** are in `src/assets/images/` (replace files, same names). The four `galeria-*.jpg` files are git-ignored on purpose: they are client photos pending permission. To show the gallery and the Instagram photo grid, add real photos with those names (or edit `gallery` in `site.ts`), set `features.showGallery = true`, and remove the ignore line in `.gitignore`.
- **Reviews** are real public Google reviews with shortened names (`// TODO(owner): confirm permission`).
- **Brand:** tokens in `src/styles/brand-theme.css` (generated from `../brand/tokens.json`); logo files in `public/logo/`.
- **`/marca`** (brand guidelines, `noindex`) is generated by `node ../brand/guidelines-build.mjs --site public/marca`.

## Deploy (GitHub Pages)

Push to `main`. `.github/workflows/deploy.yml` builds with `withastro/action` and publishes with `actions/deploy-pages`. In the repo: **Settings → Pages → Source: GitHub Actions** (one-time). The site is a user/org root site, so there is no `base` path.

## Using a real domain later

1. Register it at registro.br in the owner's name.
2. Add `public/CNAME` containing the domain (e.g. `www.example.com.br`).
3. Set the DNS records GitHub documents for Pages, then enable **Enforce HTTPS** in Settings → Pages.
4. Change `SITE_URL` in `src/data/site-url.mjs` (there is a commented example) and push.

## Google Search Console

Add the HTML-tag verification meta in `src/layouts/Layout.astro` (`<meta name="google-site-verification" ...>`), then submit `https://studiodivashair.github.io/sitemap-index.xml`.
